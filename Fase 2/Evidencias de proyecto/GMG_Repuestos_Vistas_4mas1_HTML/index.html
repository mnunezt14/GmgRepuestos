Acerca de esta documentación

Documentación generada a partir del código fuente real del sitio (public_html/ del archivo gmgrepuestos_cl.zip, versión con fecha 21-09-2026). La carpeta public_html/database/ del ZIP es una copia anterior del sitio y no se usó como fuente, salvo los scripts SQL para confirmar el esquema de la base de datos.

Nombres coherentes usados en todas las vistas

Actores: Cliente, Administrador, Asistente Virtual (como actor secundario del checkout), Mercado Pago, API IA OpenAI, Servidor SMTP Hostinger, WhatsApp GMG, Transbank WebPay (legado).

Entidades «entity» (tablas MySQL): Producto, Pedido, PedidoItem, CodigoDescuento, Administrador, ConversacionChat, MensajeChat, AvisoStock.

Fronteras «boundary» (páginas y JS): PaginaTienda (index.php), TiendaUI (tienda.js), ModelAccordion (model-accordion.js), Carrito / CarritoUI (cart.js), ChatWidget (chat.js), RetornoMercadoPago, RetornoWebpay, PaginaMiPedido, PaginaLogin, AdminDashboard, AdminProductos, AdminPedidos, AdminCodigos, AdminConversaciones.

Controles «control» (PHP del servidor): CheckoutController (checkout.php), ValidarCodigo, Relacionados, BuscarSugerencias, ModelosHelper (modelos.php), ChatController (chat.php), ChatHelpers (chat_helpers.php), RegistrarAvisoStock, FeedbackMensaje, EmailHelpers, Auth (auth.php), Logout.

Infraestructura / externos: Conexion (mysqli en config.php), SesionPHP, SmtpMailer, BotConfig, HerramientaBuscarProductos (tool de la IA), PasarelaMercadoPago, APIOpenAI, TransbankWebpay.

Notas de notación

Mermaid solo tiene nativos los diagramas de clases (classDiagram) y de secuencia (sequenceDiagram). Los de casos de uso, comunicación, componentes, paquetes, actividad y despliegue se emulan con flowchart siguiendo convenciones UML (explicadas al inicio de cada archivo). Los colores usan la paleta de marca del sitio: negro #111111, rojo #D32F2F, gris #F5F5F5 y amarillo de alerta #FFF3CD para bases de datos.

Cómo visualizar

Los bloques mermaid se renderizan directamente en GitHub, GitLab, Obsidian, Notion y en VS Code (extensión Markdown Preview Mermaid Support). Para copiar un diagrama suelto a un informe se puede pegar en https://mermaid.live y exportar a PNG o SVG. Draw.io también importa Mermaid desde Organizar → Insertar → Avanzado → Mermaid.

Hallazgos transversales documentados en las vistas

  1. Credenciales en texto plano en backend/config.php (BD y token de Mercado Pago) y backend/bot_config.php (clave de la API de IA). Se recomienda invalidarlas, moverlas fuera de public_html/ y no incluirlas en el ZIP.
  2. Confirmación de pago por parámetros GET en mercadopago_return.php; conviene verificar el pago contra la API de Mercado Pago o usar webhooks.
  3. Checkout síncrono: el correo SMTP se envía antes de llamar a Mercado Pago y sin transacción de BD.
  4. webpay_return.php es código legado no conectado al flujo (faltan las constantes WEBPAY_*).
  5. Scripts SQL dentro de public_html/database/, con un comentario que documenta la contraseña inicial de los administradores.
