Explicación teórica

La vista de desarrollo (también llamada de implementación o de gestión del software) describe cómo se organiza el código en el entorno de desarrollo: qué módulos, scripts y librerías existen, cómo dependen entre sí y en qué carpetas o capas se agrupan. Es la vista que usan los programadores para repartir trabajo, detectar acoplamientos y gestionar versiones.

Nota de notación: Mermaid no tiene diagramas de componentes ni de paquetes UML nativos; se emulan con flowchart. Los componentes se dibujan con la forma de subrutina [[ ]], los paquetes como subgraph y las dependencias como flechas punteadas rotuladas «use», «require» o «HTTP».

Explicación técnica aplicada a esta página

La página se construye con un script PHP principal que incluye (require_once) dos módulos del backend y se apoya en tres módulos JavaScript cargados en el navegador. Las hojas de estilo se cargan con un parámetro ?v=time() para evitar caché durante el desarrollo. backend/modelos.php está protegido por .htaccess (solo se puede incluir desde PHP), mientras que buscar_sugerencias.php es un endpoint público que responde JSON.

Diagrama de Componentes

Lectura: cart.js y chat.js se cargan en esta misma página pero pertenecen a los módulos Carrito y Checkout y Asistente Virtual. El único componente del servidor expuesto como API para esta página es buscar_sugerencias.php.
