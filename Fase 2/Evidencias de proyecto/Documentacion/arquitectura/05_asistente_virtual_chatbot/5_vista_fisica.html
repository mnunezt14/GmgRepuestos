Explicación teórica

La vista física mapea el software sobre el hardware: los nodos (dispositivos y servidores), los entornos de ejecución que corren sobre ellos, los artefactos desplegados en cada uno y los enlaces de comunicación con su protocolo. Es la vista que usan los ingenieros de sistemas para razonar sobre disponibilidad, seguridad de red, latencia y capacidad.

Nota de notación: el diagrama de despliegue se emula con flowchart, usando subgraph anidados para «device» y «execution environment», nodos para los «artifact» y flechas rotuladas con el protocolo.

Explicación técnica aplicada a esta página

El chatbot es el único módulo que depende de un servicio de IA externo en tiempo real. La API de OpenAI se consume servidor a servidor por HTTPS con una clave Bearer; la clave nunca llega al navegador. El reconocimiento de voz se ejecuta en el navegador del cliente (según el navegador, puede usar un servicio de voz del proveedor del navegador).

Diagrama de Despliegue

Lectura: el punto único de falla externo es la API de IA; por eso existe la degradación a modo respaldo y a WhatsApp. La base de datos sigue siendo la fuente de verdad de precio y stock, lo que materializa en la topología la restricción de control de alucinaciones.
